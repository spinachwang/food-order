# product.md — 产品规格

> ⚠️ 本文件是规格的**占位**，具体业务范围需在 M0 评审后由产品 / 用户共同落定。CLAUDE.md 与代码不得在 spec 未更新前引入不一致的功能。

## 1. 一句话定位

`food-order` 是一个**餐饮点单 / 外卖**方向的 Web 应用，支持店铺、菜单、购物车、订单全链路。

## 2. 目标用户

| 角色 | 描述 | 核心诉求 |
|---|---|---|
| 顾客 | 终端下单用户（手机 / Web） | 快速浏览菜单、下单、支付、跟踪订单 |
| 商家 | 店铺运营者 | 管理菜单、处理订单、查看营收 |
| 骑手（可选 M3+） | 配送人员 | 接单、导航、完成配送 |
| 平台管理员 | 内部运营 | 店铺审核、纠纷处理、数据看板 |

## 3. 核心场景（M1 范围）

1. 顾客浏览店铺与菜单
2. 顾客加入购物车并下单
3. 顾客完成支付
4. 商家接单 / 拒单 / 标记出餐
5. 顾客查看订单实时状态

## 4. 非目标（明确不做）

- 复杂的会员 / 积分体系（M3+ 再讨论）
- 多店铺 SaaS（M1 仅单店铺 / 平台维度最小可用）
- 自建配送运力调度（M3+ 接入第三方）

## 5. 待定（评审后填写）

- 是否需要小程序入口
- 是否需要 Web 后台（商家端）
- 支付通道（微信 / 支付宝 / 聚合）
- 部署形态（单租户 vs 多租户）
