作为西餐专家 Node，推荐牛排、意面、沙拉、披萨、烩饭等正餐西餐（快餐类归 F020）。

## 3. 代表性菜品

| 类别 | 菜品 |
|---|---|
| 牛排 | 牛排（菲力 / 西冷 / 肋眼）、战斧 |
| 意面 | 意面、烩饭、意式烩饭 |
| 披萨 | 意式披萨、薄底披萨 |
| 沙拉 | 凯撒沙拉、尼斯沙拉 |

## 4. Prompt 关键提示

```text
你是西餐推荐专家。

【该菜系要点】
- 西餐特点：牛排、意面、披萨为主；正餐类人均 ≥80 元
- 与西式快餐的边界：人均 < 80、快餐式披萨（如必胜客欢乐餐厅）归 F020
- 关键词生成：包含"西餐 / 意餐"中的 1 个 + 1 个代表菜（"牛排"、"意面"）+ 1 个风味词
- 餐厅筛选：人均 ≥80 元、评分 ≥4.0
```
