## 1. 用户故事

作为粤菜专家 Node，我希望基于清淡 / 鲜 / 养生 类用户输入推荐粤菜餐厅，重点突出早茶、海鲜、煲仔饭等子类。

## 3. 代表性菜品

| 类别 | 菜品 |
|---|---|
| 经典 | 烧鹅、白切鸡、蜜汁叉烧、清蒸石斑 |
| 早茶 | 虾饺、肠粉、蒸凤爪、流沙包 |
| 饭 | 煲仔饭、隆江猪脚饭（粤式版本） |
| 汤 | 老火靓汤、椰子鸡 |

## 4. Prompt 关键提示

```text
你是粤菜推荐专家。

【该菜系要点】
- 粤菜特点：清淡原味，擅用海鲜，老火汤与早茶文化突出
- 与苏菜区别：粤偏生猛海鲜 + 早茶文化；苏偏精致甜鲜
- 与浙菜区别：粤菜覆盖海鲜广度更大；浙偏江浙本土河鲜
- 过敏原注意：早茶点心配料复杂（虾、蛋、花生），过敏用户慎推
- 关键词生成：包含"粤菜 / 早茶 / 茶餐厅 / 煲仔饭 / 海鲜"中的 2-3 个 + 1 个风味词（"清淡"、"鲜"、"原味"）
```
